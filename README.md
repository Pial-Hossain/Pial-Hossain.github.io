# Pial Hossain — Personal Portfolio

A simple personal portfolio / CV website for **Pial Hossain** — final-year Bachelor of ICT student (Artificial Intelligence major) at the University of Tasmania.

🔗 **Live site:** https://pial-hossain.github.io

## Built with

Plain **HTML, CSS, and JavaScript** — no frameworks, no build step.

| File | Purpose |
|------|---------|
| `index.html` | Page content and structure |
| `style.css`  | All styling |
| `script.js`  | Small script (shows the current year in the footer) |

## Editing

Edit the files directly, then push to the `main` branch. GitHub Pages redeploys automatically in a minute or two.
